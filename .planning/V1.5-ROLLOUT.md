## Step 1 — Deploy

```bash
cd apps/functions
npm run build
firebase deploy --only functions --project wekruit-5f89b
```

After first deploy, get Gen2 URL for paMessageCoalescer:
```bash
gcloud functions describe paMessageCoalescer --gen2 --region=us-central1 --project=wekruit-5f89b --format='value(serviceConfig.uri)'
```

Paste URL into `apps/functions/.env`:
```
PA_COALESCE_TARGET_URL=https://...-uc.a.run.app
PA_COALESCE_INVOKER_SA=<PROJECT_NUMBER>-compute@developer.gserviceaccount.com
```

For `PA_COALESCE_INVOKER_SA` use the runtime SA of paMessageCoalescer:
```bash
gcloud functions describe paMessageCoalescer --gen2 --region=us-central1 --project=wekruit-5f89b --format='value(serviceConfig.serviceAccountEmail)'
```

Grant `roles/iam.serviceAccountTokenCreator` (project + SA self-impersonation) so Cloud Tasks can mint OIDC tokens — without this, paCoalesceBufferSweep crashloops every 60s with `missing PA_COALESCE_INVOKER_SA` (or `Permission denied on token mint` if env var present but role absent):
```bash
SA="$(gcloud functions describe paMessageCoalescer --gen2 --region=us-central1 --project=wekruit-5f89b --format='value(serviceConfig.serviceAccountEmail)')"
gcloud projects add-iam-policy-binding wekruit-5f89b --member="serviceAccount:$SA" --role="roles/iam.serviceAccountTokenCreator" --condition=None
gcloud iam service-accounts add-iam-policy-binding "$SA" --member="serviceAccount:$SA" --role="roles/iam.serviceAccountTokenCreator" --project=wekruit-5f89b
```

Then re-deploy paMessageCoalescer + paSendblueWebhook + onPaInbound + paCoalesceBufferSweep.
